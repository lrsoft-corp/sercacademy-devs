Student activity management was expanded across both the admin dashboard and the public activity flow.

The student query now returns richer activity summary data, including last activity information, total sessions, duration, games played, and current level details. Those fields are surfaced in the activity dashboard so admins can scan student progress without opening each student's detail page first.

Group management also received layout and workflow changes. The group screens now expose more relevant activity and student information, while related API handling was updated so group and activity actions remain aligned with the newer dashboard structure.
