The admin activity page received a round of usability improvements for filtering and reviewing activity data.

Pagination was added to the activity page, student search now works better across names and emails, and several activity filter bugs were corrected. The activity table also now displays a total duration summary, giving admins a quick view of the time represented by the current filter result.

Student and action views were adjusted alongside the activity page so the selected filters are applied more consistently.
